# 架构

## 分层

依赖只能向下,由 `src/architecture.rs` 的测试强制:

```text
ui  cli                 界面与命令行
app                     交互状态
engine                  模块注册、总线到界面的桥接、一次性后台任务
forensics  response     案件与证据、拦截
detection               检测引擎
process network files   领域模块与它们的探头
host performance activity
common                  路径、命令运行器、文本、节奏控制
kernel                  微内核,不依赖任何其他模块
```

## 微内核

`src/kernel/` 约 1100 行,只有:

| 文件 | 职责 |
|---|---|
| `bus.rs` | 事件总线:有界队列,发布永不阻塞 |
| `module.rs` | 模块接口、能力声明、运行上下文 |
| `supervisor.rs` | 注册、生命周期、调度、看门狗、崩溃重启 |
| `model.rs` | 统一指标模型 |
| `alerts.rs` | 指标告警 |
| `config.rs` | 模块配置 |

使用和扩展见[模块与微内核](modules.md)。

## 数据如何到达界面

```text
探头 → 模块 → 总线 → engine/bridge → WorkerMsg → 主线程 → 绘制
```

`bridge` 是唯一同时认识模块事件和 `WorkerMsg` 的地方,所以 `App` 不依赖模块如何排列。进程表和连接表来自两个模块,由它合并成快照;第一份连接数据到达前快照会等最多 2 秒,否则所有现存连接都会被当成新连接。

**主线程不做阻塞工作。** 主线程的消息处理有 40 ms 预算。没有预算时,消息来得比处理快就永远退不出循环,按键和绘制都会饿死。这曾经是真实 bug。

## 背压与上限

| 位置 | 机制 |
|---|---|
| 事件总线 | 每订阅者有界队列,溢出丢弃并计数 |
| 快照 | 队列中超过 2 个时暂停采样 |
| 文件事件 | 每秒 2000 条,丢弃计数 |
| 活动事件 | 合并、每秒 2 万条、保留 20 万条 |
| 拦截决策 | 队列 1 万条,处理内核请求的线程绝不等待日志 |
| 时间线重建 | 自动重建最多占主线程约 5% |
| Activity 视图 | 同上,用序号而不是下标,旧记录淘汰后不错位 |
| 事件历史 | 总量 256 MB,保留 14 天,运行中定期清理,单日有上限 |
| 外部命令 | 必有超时,输出上限 256 MB,孙进程占用管道不会让调用挂起 |

## 不可信输入

被调查的系统可能是敌对的,所以这些都视为不可信:文件内容和文件名、进程名和命令行、案件目录、规则文件。

- 解析器做模糊测试,要求不崩溃、2 秒内完成。
- 字符串切片不使用未校验的字节下标。
- 拼入 PowerShell 的路径经过 `ps_quote`,它转义包括弯引号在内的全部单引号字符。
- 打开文件前确认是普通文件,FIFO 和设备文件会阻塞或读不完。
- 导出的 CSV 中和公式;输出到终端的文本清除控制字符。

因为 procwatch 通常有较高权限,还要防范:

- **程序劫持**:系统工具从系统目录运行,不走 `PATH`。
- **共享目录**:案件、导出、临时文件独占创建,不跟随符号链接。
- **敏感数据**:事件历史和证据只有当前用户可读,因为命令行里可能有密码。
- **策略文件**:其他用户可写的策略被拒绝。
- 规则解析限制嵌套深度,因为栈溢出无法捕获。

## 数据流:从事件到检测

1. 来源产生事件,进入 `WorkerMsg`。
2. 主线程更新环形缓冲,写入事件历史。
3. `rebuild_timeline` 合并所有来源,聚类,运行行为序列规则。
4. `triage_all` 每次快照评估主机规则和 Sigma 规则。
5. 检测进入 `Store`,按规则和实体去重。

## 性能实测

Windows Server CI 上的改进,单位是单次最长耗时:

| 阶段 | 修复前 | 修复后 |
|---|---|---|
| 单次快照处理 | 3186 ms | 100 ms |
| `cluster` | 1890 ms | 14 ms |
| `behaviour` | 1342 ms | 86 ms |

根因是两个算法问题:`DateTime<Local>` 运算写在内层循环里,以及每个事件都搬动全部未完成序列。
