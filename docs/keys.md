# 按键参考

这里列出 procwatch 每个界面的每一个按键。在程序里按 `?` 可看当前页面的简要版本,按 `:` 或 `ctrl+k` 可按名称搜索操作。

按键区分大小写:`d` 和 `D` 是不同的操作,`D` 表示 Shift+D。

中文输入法下打出的全角标点(`！` `？` `：` `、`)和对应的半角键效果相同。设置键例外,只认英文逗号 `,`。输入框里保持原样。

## 启动阶段

程序启动后先运行自检,然后进入 STANDBY。这期间只有下面的按键有效。

STANDBY:

| 按键 | 功能 |
|---|---|
| `Enter` `Space` | 选择本次要加载的模块 |
| `,` | 打开设置 |
| `q` | 退出 |

选择模块:

| 按键 | 功能 |
|---|---|
| `↓` `j` | 下一个 |
| `↑` `k` | 上一个 |
| `Space` | 勾选或取消 |
| `a` | 全选 |
| `n` | 全不选 |
| `Enter` | 加载已勾选的模块 |
| `Esc` | 回到 STANDBY |

自检、加载和完整性校验期间,以及自检失败时,只有 `q` 退出和 `ctrl+c` 有效。

页面键对应的模块没有加载时,页面不出现,按键只提示。

## 查找按键的顺序

一次按键按下面的顺序处理,先命中的生效:

1. `ctrl+c` 在任何界面都退出程序。
2. 如果打开了弹窗(帮助、菜单、确认框、输入框等),由弹窗处理,页面收不到按键。
3. 如果显示着 `f` 查找的结果,由查找结果处理。
4. 全局按键。
5. 当前页面的按键。

因此,页面表格里列出的按键,只有在没有打开弹窗时才生效。

## 搜索语法

`/` 搜索框里的文字是不区分大小写的子串。时间线页还支持:

| 写法 | 含义 |
|---|---|
| `tree:PID` | 只看这个进程及其子孙的事件 |
| `cluster:N` | 只看第 N 个活动簇 |
